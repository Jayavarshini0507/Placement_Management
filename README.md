# Placement Management System

A full-stack web application designed to simplify placement management by managing student and company information and identifying student eligibility for company-specific opportunities.

## 🚀 Features

- Student management with CRUD operations
- Company information management
- CGPA-based eligibility screening
- REST API integration between frontend and backend
- Persistent data storage using MySQL
- React-based user interface
- Spring Boot backend with JPA/Hibernate
- Separation of frontend and backend components
